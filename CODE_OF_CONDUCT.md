# Кодекс поведения

## Наши правила

- Обсуждаем код и поведение программы, а не личность собеседника.
- Критика — по существу: что не работает, в каких условиях, чем подтверждается.
- Уважаем разный опыт: у кого-то PowerShell 7, у кого-то 5.1 и Windows 10 без обновлений.
- Не публикуем чужие персональные данные, токены, конфиги и переписку.
- Политические и религиозные темы — вне проекта.

## Недопустимо

- оскорбления, угрозы, травля, дискриминация по любому признаку;
- спам, реклама, массовые упоминания;
- публикация секретов и приватных данных — даже «для примера»;
- намеренная порча обсуждений (троллинг, флуд, провокации).

## Модерация

Нарушения разбираются по порядку: замечание → предупреждение → блокировка участия. Решение принимает мейнтейнер. Апелляция — в личных сообщениях, не в публичном обсуждении.

## Область действия

Правила действуют в Issues, pull request'ах, обсуждениях и любых пространствах, где проект представлен официально.
