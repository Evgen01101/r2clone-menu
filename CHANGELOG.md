# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — по [SemVer](https://semver.org/lang/ru/).

## [1.3.0] — 2026-10-27

### Добавлено

- Каталог провайдеров: Яндекс.Диск, Google Drive, OneDrive, S3-совместимые хранилища и Dropbox. Для каждого типа заданы backend rclone, поля формы настройки доступа, подсказка по авторизации, режим входа (`requiresApp`/`optionalApp`/`interactiveOnly`), атрибуция, разрешённые флаги и ключи конфига.
- Переопределение каталога файлом `R2clone_menu.providers.json` рядом со скриптом: запись с тем же `type` полностью заменяет встроенную, остальные остаются. При битом JSON оверрайд игнорируется. Образец — `R2clone_menu.providers.example.json`.
- Схема настроек v2 в `R2clone_menu.config.json`: `schemaVersion`, `paths.dataRoot` (`portable` | `user`), `paths.logDir`, `default` и `remotes` с `type`, `localRoot`, `extraFlags`, `backendOptions`. Старая схема v1 с `roots` мигрирует автоматически.
- Корень данных: `portable` — папка `data` рядом со скриптом (по умолчанию), `user` — `%LOCALAPPDATA%\R2clone_menu\data`.
- Пункт 20 «Хранилища»: список remote с типами и локальными папками, текущее хранилище и хранилище по умолчанию; переключение, добавление (пункт 18), смена локальной папки (пункт 12), назначение по умолчанию, удаление.
- Пункт 21 «Расширенные настройки»: дополнительные флаги и ключи конфига на конкретное хранилище с проверкой по allowlist и denylist, показ текущего набора и сброс к умолчаниям.
- Атрибуция API в шапке меню выводится из каталога (Яндекс.Диск — п. 2.4).

### Изменено

- Пункт 18 переписан под профиль провайдера: поля и подсказка берутся из каталога, ключи передаются динамически, для `interactiveOnly` открывается интерактивный `rclone config`.
- Локальная папка по умолчанию — `<корень данных>\<тип>\<remote>`; в конфиге она хранится относительным путём, если лежит внутри корня.
- Шпаргалка и подсказки используют имя текущего remote вместо жёстко зашитого `ydisk:`.
- README (русский и английский): раздел «Другие облака» описывает каталог, оверрайд и пункты 20–21.
- Версия программы поднята до 1.3.0.

### Исправлено

- Хардкод `ydisk:` в шпаргалке и примеры команд меню, не работавшие для remote с другим именем.

## [1.2.1] — 2026-10-26

### Добавлено

- Атрибуция API в интерфейсе: для remote типа `yandex` в шапке меню выводится строка «Доступ к Диску: официальный API Яндекса» (п. 2.4 Условий использования API Яндекс.Диска).
- В README (русская и английская версии) — блок атрибуции с официальным логотипом Яндекс.Диска и ссылкой на бренд-систему Яндекс 360.
- Раздел «Назначение и границы применения»: только собственные файлы авторизованного аккаунта, без чужих аккаунтов и массового файлообмена (п. 2.8 и 2.17 Условий использования Яндекс.Диска).
- Предупреждение о лимите 40 запросов в секунду в README и в шпаргалке меню (п. 2.2 Условий использования API).

### Изменено

- Заголовок README: «консольное меню для облачных хранилищ (сейчас — Яндекс.Диск)», в английской версии аналогично — товарный знак больше не используется как идентичность продукта.
- Все абсолютные пути в документации заменены шаблонами `<папка проекта>` и `<папка дисков>`.
- Версия программы поднята до 1.2.1.

## [1.2.0] — 2026-10-25

### Добавлено

- Загрузка папки на Диск (пункт 10): выбор локальной папки в диалоге или вводом пути, предпросмотр «источник → назначение», число файлов и объём, подтверждение перед стартом. Содержимое попадает в подпапку с именем источника внутри текущей папки Диска.
- Загрузка отдельного файла на Диск (пункт 11) через `rclone copyto`.
- Выбор локальной папки для каждого remote (пункт 12): диалог, ручной ввод или сброс к папке по умолчанию. Хранится в `R2clone_menu.config.json` рядом со скриптом.
- Папка по умолчанию, если настройка не задана: `<папка дисков>\<remote>`.
- `R2clone_menu.config.example.json` — образец файла настроек для публикации.
- В шапке меню показывается источник локальной папки: параметр запуска, файл настроек или значение по умолчанию.

### Изменено

- Меню расширено до 19 пунктов, нумерация сдвинута: квота — 13, диагностика — 14, журнал — 15–17, учётные данные — 18, шпаргалка — 19.
- Параметр `-LocalRoot` по умолчанию пуст: жёсткий путь больше не зашит в скрипт.
- Журнал размещается рядом с локальной папкой, путь вычисляется динамически.
- Проект переименован в **R2clone_menu** (папка, файлы, конфиг).

### Исправлено

- Проверка существования локальной папки и предложение создать её при первом скачивании.
- Единая обработка номеров пунктов списка (`Select-Number`), убрано дублирование разбора ввода.

## [1.1.0] — 2026-10-25

### Исправлено

- Разбор списка папок: `ConvertFrom-Json` отдавал массив одним объектом, из-за чего счётчик содержал один элемент и любой номер, кроме первого, отвергался как «нет такого номера».
- Сортировка списка: папки теперь идут выше файлов, нумерация соответствует отображаемому порядку.

### Изменено

- `R2clone_menu.bat` переведён на концы строк CRLF, добавлены `title`, стартовая строка, `cd /d "%~dp0"` и сообщение с кодом возврата — пустая консоль при двойном клике больше не возникает.

## [1.0.0] — 2026-10-24

### Добавлено

- Навигация по Яндекс.Диску: листинг папок и файлов с размерами и датами, вход по номеру, подъём на уровень, переход в корень.
- Размер текущей папки и свободное место на локальном диске, квота Диска.
- Скачивание папки, отдельного файла и всей ветки с прогрессом и журналом.
- Автоматическая сверка после копирования и отдельная проверка локальной копии (`rclone check --one-way`).
- Разбор журнала: последние ошибки и их количество.
- Настройка доступа: ввод `ClientID` и `Client secret`, пересоздание remote, повторная авторизация в браузере.
- Диагностика доступа и шпаргалка по rclone.
- Документация: установка rclone, создание собственного OAuth-приложения Яндекса, разбор типовых ошибок (401, 402, 403, 410, 429/509), ограничения и меры безопасности.
